# React Native Custom Component with FlatList

This project demonstrates how to display a list of contacts using **FlatList** and a **custom component**.

## What I Learned

* `FlatList`
* `renderItem`
* `keyExtractor`
* Passing data using props
* Creating reusable custom components
* Displaying multiple contacts
* Styling list items with `StyleSheet`

## Project

I created a **Contact List** that displays:

* Name
* Email

Each contact is displayed using a separate **custom component**.

### Main Concepts

```text
Data → FlatList → renderItem → Custom Component → Props
```
