# React Native Grid View

This project demonstrates how to create a **Grid View in React Native** using `ScrollView` and JavaScript `.map()`.

## What is Grid View?

Grid View displays items in **rows and columns**, such as products, images, or categories.

## What I Learned

* `ScrollView`
* `.map()` for rendering multiple items
* Creating 2-column layouts using `flexDirection` and `flexWrap`
* Passing data to components using props
* Displaying images with `Image`
* Creating reusable product cards
* Styling cards using `StyleSheet`
* Using `borderRadius`, shadows, spacing, and colors

## Project

I created a **Product Grid** that displays products with:

* Product image
* Product name
* Product price
* Card-style layout

### Main Concepts

```text
Data → map() → Product Card → Props → Styling
```

This project helped me understand how to create a simple **e-commerce-style product grid** in React Native without using `FlatList`.
