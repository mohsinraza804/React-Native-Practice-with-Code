# React Native TextInput Practice

This project is created to practice **TextInput and form handling in React Native**.

## What I Practiced

* `TextInput`
* `useState`
* `onChangeText`
* `value`
* `placeholder`
* `secureTextEntry`
* Input validation
* Error messages
* Character counter
* Password show/hide
* Login form
* Registration form
* Search/filter input
* Dynamic form data
* Multiple inputs
* Submit and Clear buttons
* Working with arrays using `map()` and `filter()`

## Practice Goal

The goal of this project is to understand how to **take user input, store it in state, validate it, and display/update data dynamically** in React Native.
