# React Native Props Practice

This project is a small React Native practice app created to understand **Props, State, and passing functions between components**.

## What is happening?

* **User Profile:** User data is passed from `App.js` to child components using props.
* **Counter:** `count` state is managed in `App.js` and updated through functions passed as props.
* **Todo List:** Todos are displayed using `map()` and deleted using `filter()`.
* **Product List:** Products are passed to components using props.
* **Shopping Cart:** Products can be added and removed from the cart using state and props.
* **Component Communication:** Parent components pass data and functions to child components using props.

## Concepts Practiced

* React Native Components
* Props
* `useState`
* `map()`
* `filter()`
* Callback Functions
* Parent → Child Data Passing
* Child → Parent State Updates
* Component Reusability

## Technologies

* React Native
* JavaScript
* React Hooks

## Purpose
The main purpose of this project is to practice **props passing and state management between multiple React Native components**.
