# React Native Login Form

A simple React Native Login Form project with a loading indicator.

## Features

- Name input
- Password input
- Form validation
- Login button
- ActivityIndicator
- 3-second loading simulation
- Login success message
- Styled UI

## What is ActivityIndicator?

`ActivityIndicator` is a React Native component that shows a loading spinner while something is processing or loading.

Example:

```jsx
<ActivityIndicator size="large" color="blue" />
